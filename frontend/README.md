# Expense Tracker — frontend

React + Vite + TypeScript + Tailwind v4. UI components adapted from [Opensource UI](https://opensourceui.in) (MIT) — see `src/components/opensourceui/`.

```powershell
npm install
npm run dev        # http://localhost:5173
```

The backend must be running at the URL in `.env` (`VITE_API_URL`, default `http://127.0.0.1:8000`).
